# Configuration

---

## config/paths.json (v1.3.0)

Primary configuration file. All paths are resolved at runtime by `src/lib/paths.js`.

```json
{
  "inboxRoot": "G:\\My Drive\\Cast Iron Charlie — Documentary Project\\Research",
  "processedRoot": "{inboxRoot}\\CIC_Processed",
  "sidecarsRoot":  "{inboxRoot}\\CIC_Sidecars",
  "bundlesRoot":   "{inboxRoot}\\CIC_Bundles",
  "archiveRoot":   "{inboxRoot}\\_Archive",
  "status": {
    "harvester": "{inboxRoot}\\CIC_Processed\\_status\\harvester.json",
    "sweeper":   "{inboxRoot}\\CIC_Processed\\_status\\sweeper.json",
    "indexer":   "{inboxRoot}\\CIC_Processed\\_status\\indexer.json",
    "corpus":    "{inboxRoot}\\CIC_Processed\\_status\\corpus.json",
    "startup":   "{inboxRoot}\\CIC_Processed\\_status\\startup.json"
  },
  "sweeper": {
    "scanParentFolder": false,
    "ignoreNames": ["_archive", "_Archive", "Index", "Search"]
  },
  "externalSources": {
    "nasm":   "{inboxRoot}\\Daily Intake\\NASM",
    "burton": "{inboxRoot}\\Daily Intake\\BurtonHistorical"
  }
}
```

### Field Reference

| Field | Description |
|-------|-------------|
| `inboxRoot` | `CIC_ROOT` — root of research drive. Overridable via `CIC_ROOT` env var. |
| `processedRoot` | Where harvested files land after sweeping. |
| `sidecarsRoot` | Sidecar JSON files (one per indexed file). |
| `bundlesRoot` | Batch and corpus bundle JSON output. |
| `archiveRoot` | External source archive. |
| `status.*` | Per-stage status JSON file paths. |
| `sweeper.scanParentFolder` | If `false`, sweeper does not recurse into parent directories. |
| `sweeper.ignoreNames` | File/folder names the sweeper silently skips. |
| `externalSources` | Named drop directories for external institutional sources. |

### Template interpolation

Use `{inboxRoot}` in any path value — it is replaced at runtime with the resolved `CIC_ROOT`.

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `CIC_ROOT` | value from `config/paths.json` | Override the research drive root |
| `NODE_ENV` | `development` | `production` disables debug output |
| `CIC_DB_PATH` | `data/cic.db` | Override DB path (absolute path) |
| `CIC_LOG_LEVEL` | `info` | Log verbosity: `debug` \| `info` \| `warn` \| `error` |
| `PORT` | `3000` | Castironforge HTTP port |

Set via `.env` (loaded with `dotenv`) or system environment.

## Path Resolution

Implemented in `src/lib/paths.js` (v1.1.1). Resolution order:

1. **CIC_ROOT** (for inboxRoot):
   - `process.env.CIC_ROOT` (highest priority)
   - `config.inboxRoot` from `paths.json`
   - `PROJECT_ROOT` (fallback — development only)

2. **PROJECT_ROOT** (for db path, logs, scripts):
   - Derived from `import.meta.url` — always 2 levels up from `src/lib/paths.js`
   - Never relative to CIC_ROOT

3. **DB path**:
   - Always `PROJECT_ROOT/data/cic.db`
   - Never stored on the research drive

## npm Scripts

```bash
# Environment
npm run init                  # Bootstrap folders + DB schema
npm run validate              # Check all required dirs exist (exit 1 if missing)
npm run maintain              # Heal missing dirs + write startup.json

# Pipeline
npm run all                   # Full 8-stage pipeline
npm run daily:orchestrated    # Daily pipeline: stages 2–6 + status
npm run harvester             # Run harvester only
npm run sweeper               # Run sweeper only
npm run indexer               # Run indexer + bundle builder

# Status
npm run status                # Print status report
npm run status:json           # Print status as JSON

# Database
npm run reset:db -- --confirm      # Wipe + rebuild DB (destructive)
npm run reset:status -- --confirm  # Reset all status JSON files
```

## Sweeper ignoreNames

Files or directory names in this list are silently skipped by the sweeper scanner. Default set:

| Name | Reason |
|------|--------|
| `_archive` | Legacy archive folder — not an inbox item |
| `_Archive` | Windows case variant |
| `Index` | Search index files generated by Windows |
| `Search` | macOS Spotlight / Windows Search metadata |

Add entries to `config/paths.json → sweeper.ignoreNames` to extend.

## Bundle Output Format

**Batch bundle** (`CIC_Bundles/batches/batch-YYYY-MM-DD-<category>.json`):

```json
{
  "_schema": "cic-bundle-batch-v1.0.0",
  "bundle_id": "batch-2026-05-03-documents",
  "bundle_type": "batch",
  "date_label": "2026-05-03",
  "category": "documents",
  "run_id": "pipeline-2026-05-03T09:00:00.000Z",
  "created_at": "2026-05-03T09:02:00.000Z",
  "file_count": 9,
  "files": [...],
  "entity_summary": [...],
  "topic_summary": [...]
}
```

**Corpus bundle** (`CIC_Bundles/corpora/<corpus>.json`):

```json
{
  "_schema": "cic-corpus-v1.0.0",
  "corpus_name": "people",
  "bundle_type": "corpus",
  "entry_count": 147,
  "entries": [
    { "entity_type": "PERSON", "value": "Charles E. Sorensen", "mention_count": 83, "file_ids": [...] }
  ]
}
```
