# MEE Finding Assessor (Phase 45.4)

Assess and score findings from MEE phase execution with weighted confidence scoring.

## Purpose

Analyzes findings generated by earlier phases and scores them using a weighted confidence model combining confidence, impact, and effort metrics.

## Input

- `findings`: Array of finding objects with id, type, title, description, confidence (0-1), impact (0-1)
- `scoringWeights`: Optional custom weights for confidence/impact/effort scoring
- `returnTopN`: Limit results to top N findings (default: 10)

## Output

```json
{
  "success": true,
  "assessmentId": "assess-...",
  "findings": [...],
  "stats": {
    "averageScore": "0.75",
    "topScore": 0.95
  }
}
```

## Example

```javascript
const result = await meeFindingAssessor({
  findings: [
    {
      id: "perf-001",
      type: "performance",
      title: "Cache optimization",
      description: "Add memoization",
      confidence: 0.85,
      impact: 0.78
    }
  ],
  returnTopN: 10
});
```

## Error Handling

Returns `success: false` if findings are missing or invalid.
