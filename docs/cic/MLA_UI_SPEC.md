# CIC Memory Explorer — UI Specification

## Purpose
Provide operators with a visual interface to inspect CIC’s historical evolution, trends, regressions, and long-horizon patterns.

## Panels

### 1. Timeline View
- Scrollable chronological list of memory events.
- Filters: event type, date range, subsystem.
- Click to expand payload.

### 2. Trend Graphs
- Prompt drift over time.
- Docs build success rate.
- ARPS run frequency + outcomes.
- Lane progress velocity.

### 3. Hotspot Detector
- Subsystems with repeated failures.
- Prompts with repeated drift.
- Lanes with stalled progress.

### 4. Weekly & Monthly Reports
- Generated by Memory Synthesizer.
- Downloadable as JSON or Markdown.

### 5. Event Inspector
- Raw JSON view.
- Schema validation status.
- Cross-links to related events.

## API Endpoints Used
- `GET /v1/memory/events`
- `GET /v1/memory/events?type=...`
- `GET /v1/memory/trends`

## Operator Actions
- Filter, search, inspect.
- Export summaries.
- Trigger Memory Synthesizer run.
