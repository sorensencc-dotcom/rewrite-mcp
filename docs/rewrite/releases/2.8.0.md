# CIC [2.8.0] - 2026-05-20 Release Notes

## MAS & Intelligence Fabric
- **Phase 27G — MAS-Aware Waterfall**: MAS routing decisions and signals now flow into the telemetry stream and appear inline in the intelligence timeline and per-run waterfall traces, keyed by `correlationId`.
- **Telemetry Emitters** (`apps/cic-pms/src/telemetryClient.js`): Added `emitMASDecision` and `emitMASSignal` posting best-effort to `/ingest/mas_decision` and `/ingest/mas_signal` on the telemetry server.
- **MAS Telemetry Wiring** (`projects/cic/orchestrator/src/mas/mas.js`): Imported both emitters; `processTelemetry` now calls `emitMASDecision` (with directive, drift, confidence, reason, correlationId) and `emitMASSignal` after every blackboard write.
- **Waterfall Renderer** (`apps/operator-ui/js/waterfallRenderer.js`): Added `mas_decision` rendering with `!!`/`!`/` ` severity prefixes and `mas_signal` as heartbeat rows, both showing drift and confidence values.
- **Intelligence Timeline** (`apps/operator-ui/dashboard/index.html`): Added `mas_decision` and `mas_signal` cases to the timeline switch block, displaying agent, directive, drift, confidence, and reason inline with other event types.
